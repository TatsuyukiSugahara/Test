# 00. 企画概要(要求仕様・一次資料)

> 対象コミット: ccfce22 / 最終更新: 2026-09-06

ユーザー要求を整理した一次資料。他の設計書はここで採番した要求 ID(R-xx)を参照する。

## 1. 目的

- エンジンの総合動作確認(ECS / Level / 非同期ロード / レンダリング / UI / 入力 / サウンド)。
- 「設計 → 実装 → 評価」の AI 駆動開発サイクルの実践台。

## 2. ゲーム概要

3D ハイスピードアクション。コースを走り抜け、コインを集めてゴールを目指す。
時速 300km 級のスピード感(本家準拠)を演出面の最重要項目とする。

## 4. 受け入れ条件(全体)

- 1 台のパッドでタイトル → ステージ選択 → インゲーム → クリア/落下 → リザルト → 各遷移が一巡する。
- ~~4 台のパッドを挿すと 4 分割画面で同時プレイできる。~~(R-07 変更により削除。エンジンのマルチビュー機能は P5 で実装・検証済み)
- 最高速走行時にモーションブラーがかかり、ループを走り切れる。
- コイン数と経過時間でリザルトのランクが変わる。
- ステージ追加が `.stage.json` + `.level.json` の追加だけで完結する(コード変更なし)。

## 5. スコープ外(今回はやらない)

- 敵キャラクター・攻撃アクション・リング(ダメージ)システム。
- ネットワーク対戦。
- 本番品質のアートアセット(タイトル画像などは仮素材 → R-02 は差し替え可能な構造まで)。
