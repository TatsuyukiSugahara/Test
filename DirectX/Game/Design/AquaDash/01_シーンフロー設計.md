# 01. シーンフロー設計

> 対象コミット: ccfce22 / 最終更新: 2026-09-06
> 対応要求: R-01, R-03〜R-06, R-16([00_企画概要.md](00_企画概要.md))

既存の `app::GameFlow` + `IGameState`(`Game/Application/GameFlow.h`)をそのまま使い、
状態クラスを追加して構成する。中央 switch は編集しない(現行の流儀を維持)。

## 1. 状態遷移図

```
TitleState ──決定──▶ LoadingState ──ロード完了──▶ InGameState ──┬─ゴール──▶ ResultState(クリア)
   ▲   ▲                (非同期)                                  └─全員落下─▶ ResultState(ゲームオーバー)
   │   │                                                                   │
   │   └────────────────「タイトルへ」──────────────────────────────────────┤
   │        「もう一度」→ LoadingState(同じステージ) ◀─────────────────────┤
   └──────  「次のステージへ」→ LoadingState(次ステージ) ◀─────────────────┘
```

## 2. 状態クラス責務表

配置: `Game/Application/Flow/`

| クラス | 責務 |
|---|---|
| `TitleState` | タイトル UI 表示。ステージ一覧(StageRegistry)からの選択、参加人数確定(押したパッド=参加)。決定で選択ステージを `GameContext` に書いて Loading へ |
| `LoadingState` | `LevelManager` 非同期ロード(既存 `LevelLoadHandle`)+ ステージ定義(`.stage.json`)のパース完了を待つ。既存 `LoadingScreen` を流用 |
| `InGameState` | プレイヤー生成(参加人数分)、経過時間の計時、クリア/全滅判定の監視。ゴール到達 or 全員落下で Result へ |
| `ResultState` | **レベルはアンロードせず**(R-04)、プレイヤー入力とゲーム System の更新のみ停止。リザルト UI(ランク・コイン・時間)と 3 択メニューを表示。選択に応じて遷移 |

### 状態間共有データ: `GameContext`

`GameFlow` のメンバとして追加する(状態間で受け渡す値の置き場)。

| データ | 用途 |
|---|---|
| `selectedStageIndex` | タイトルで選んだステージ(StageRegistry のインデックス) |
| `joinedPadMask` | 参加プレイヤーのパッド番号ビットマスク(R-07) |
| `playResult` | クリア可否・経過時間・プレイヤー毎コイン枚数(Result で評価) |

## 3. リザルトの「インゲーム背景」実現方式(R-04)

- ResultState の `OnEnter` でゲーム側 System(移動 / コイン / カメラ追従)を
  **一時停止フラグ**(`GameplayPauseComponent` をシングルトンエンティティに付与)で止める。
  描画・アニメ・パーティクルの System は動かし続けるため、背景は生きたまま。
- カメラはゴール地点(またはゲームオーバー地点)をゆっくり周回するリザルト用挙動に切り替える
  ([02_ECS設計.md](02_ECS設計.md) のカメラモード)。
- 「もう一度」はレベル再ロードではなく **リスポーン + 計時リセット**で即再開する
  (ロード時間ゼロ。コイン再配置はコイン Entity の再活性化で行う)。

## 4. 非同期処理の方針(R-16)

| 処理 | 経路 |
|---|---|
| レベル(ステージ)ロード | 既存 `LevelManager` の非同期ロード(`LevelLoadHandle`)をそのまま使用 |
| ステージ定義パース | `.stage.json` は小さいのでロードジョブ内で併せて読む(ThreadPool) |
| UI テクスチャ事前ロード | 既存 `GameFlow::preloaded_` の仕組みに乗せる |
| GPU リソース生成 | 規約どおりメインスレッドの `ResourceManager::Update()` に集約(architecture.md §5) |

## 5. ステージ選択の構造(R-01)

- `StageRegistry`: `Assets/Stages/StageList.json` を読み、ステージ定義
  ([03_ステージデータ仕様.md](03_ステージデータ仕様.md))の一覧を保持する。
- タイトルの選択 UI は Registry の件数分だけ項目を生成(1 件でもリスト表示)。
- 「次のステージへ」は Registry の次インデックス。末尾ならメニューから項目を消す。
