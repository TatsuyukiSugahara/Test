# 03. ステージデータ仕様

> 対象コミット: ccfce22 / 最終更新: 2026-09-06
> 対応要求: R-01, R-03, R-11〜R-13([00_企画概要.md](00_企画概要.md))

ステージを「処理共通・データ差し替え」(R-03)にするためのフォーマット定義。
見た目(地形・装飾・ライト)は既存の `.level.json`(Level システム)に置き、
ゲームルール(コース・コイン・ランク条件)は新設の `.stage.json` に分離する。

## 1. ファイル配置

```
Game/Assets/Stages/
├── StageList.json            … ステージ一覧(タイトルの選択肢の元)
├── Stage01.stage.json        … ステージ定義(ルール)
└── Stage01.level.json        … 見た目(Level システムでロード)
```

## 2. StageList.json

```json
{
	"stages": [
		{ "id": "Stage01", "name": "GREEN COAST", "stage": "Assets/Stages/Stage01.stage.json", "thumbnail": "Assets/UI/AquaDash/Stage01_thumb.png" }
	]
}
```

- 配列順 = タイトルでの表示順 = 「次のステージへ」の順。

## 3. *.stage.json

```json
{
	"level": "Assets/Stages/Stage01.level.json",
	"course": {
		"width": 12.0,
		"points": [
			{ "position": [0, 0, 0],    "up": [0, 1, 0] },
			{ "position": [0, 0, 200],  "up": [0, 1, 0] },
			{ "position": [0, 30, 260], "up": [0, 0, -1] },
			{ "position": [0, 60, 200], "up": [0, -1, 0] }
		]
	},
	"spawn":  { "distance": 0.0, "lanes": [-4.5, -1.5, 1.5, 4.5] },
	"goal":   { "distance": 7800.0 },
	"fall":   { "heightThreshold": -30.0 },
	"coins":  [
		{ "distance": 120.0, "lateral": 0.0, "height": 1.0 },
		{ "distance": 125.0, "lateral": 0.0, "height": 1.0 }
	],
	"rank": {
		"parTimeSec": 180.0,
		"thresholds": [
			{ "rank": "S", "score": 0.90 },
			{ "rank": "A", "score": 0.70 },
			{ "rank": "B", "score": 0.50 },
			{ "rank": "C", "score": 0.00 }
		]
	}
}
```

### 各セクションの意味

| セクション | 内容 |
|---|---|
| `level` | 併せてロードする Level(地形メッシュ・装飾・ライト)。コース路面メッシュもここに置く |
| `course` | Catmull-Rom スプラインの制御点列。`up` を回転させるとループ・ひねりになる(R-13)。`width` は路面幅(レーン移動の可動域) |
| `spawn` | 開始 distance と 4 人分のレーンオフセット |
| `goal` | ゴール判定の distance(R-05) |
| `fall` | スプライン路面からの相対 height がこの値を下回ったら落下(R-05) |
| `coins` | コイン配置(スプライン座標)。個数の合計がランク計算の分母(R-11) |
| `rank` | 評価。`score = 0.6 × コイン取得率 + 0.4 × min(1, parTime / クリアタイム)` を上から判定 |

- ゲームオーバー時(落下でリタイア)はランクなし。
- 補間は Catmull-Rom(制御点を通る・実装が単純)。`up` も球面補間して連続にする。
- コインが多い場合の量産は、当面 JSON を AI に生成させる運用とし、
  必要になったらエディタ拡張を検討(スコープ外)。

## 4. ロード経路

1. `LoadingState` が `.stage.json` を ThreadPool で読みパース → `StageData`(不変)を構築。
2. `level` を `LevelManager` で非同期ロード(既存経路)。
3. 両方の完了で、`StageData` からコイン・ゴールの Entity 群を遅延生成
   (既存 Prefab/Spawner の遅延ビルド経路を流用)して InGame へ。
