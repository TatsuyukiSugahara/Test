# 03. ステージデータ仕様

> 対象コミット: af67223 / 最終更新: 2026-09-11
> 対応要求: R-01, R-03, R-11〜R-13([00_企画概要.md](00_企画概要.md))

ステージを「処理共通・データ差し替え」(R-03)にするためのフォーマット定義。
見た目(地形・装飾・ライト)は既存の `.level.json`(Level システム)に置き、
ゲームルール(コース・コイン・ランク条件)は新設の `.stage.json` に分離する。

## 1. ファイル配置

```
Game/Assets/Stages/
├── StageList.json            … ステージ一覧(タイトルの選択肢の元)
├── Stage01.stage.json        … ステージ定義(ルール)
└── Stage01.level.json        … 見た目(Level システムでロード)
```

## 2. StageList.json

```json
{
	"stages": [
		{ "id": "Stage01", "name": "GREEN COAST", "stage": "Assets/Stages/Stage01.stage.json", "thumbnail": "Assets/UI/AquaDash/Stage01_thumb.png" }
	]
}
```

- 配列順 = タイトルでの表示順 = 「次のステージへ」の順。

## 3. *.stage.json

```json
{
	"level": "Assets/Stages/Stage01.level.json",
	"course": {
		"width": 12.0,
		"points": [
			{ "position": [0, 0, 0],    "up": [0, 1, 0] },
			{ "position": [0, 0, 200],  "up": [0, 1, 0] },
			{ "position": [0, 30, 260], "up": [0, 0, -1] },
			{ "position": [0, 60, 200], "up": [0, -1, 0] }
		]
	},
	"spawn":  { "distance": 0.0, "lanes": [-4.5, -1.5, 1.5, 4.5] },
	"goal":   { "distance": 7800.0 },
	"fall":   { "heightThreshold": -30.0 },
	"coins":  [
		{ "distance": 120.0, "lateral": 0.0, "height": 1.0 },
		{ "distance": 125.0, "lateral": 0.0, "height": 1.0 }
	],
	"rank": {
		"parTimeSec": 180.0,
		"thresholds": [
			{ "rank": "S", "score": 0.90 },
			{ "rank": "A", "score": 0.70 },
			{ "rank": "B", "score": 0.50 },
			{ "rank": "C", "score": 0.00 }
		]
	}
}
```

### 各セクションの意味

| セクション | 内容 |
|---|---|
| `level` | 併せてロードする Level(地形メッシュ・装飾・ライト)。(変更 2026-09-09 P18)路面メッシュは Level 配置ではなく、`course` のスプラインからロード時に手続き生成する(データ追加不要でステージ追加が完結する方を優先) |
| `course` | Catmull-Rom スプラインの制御点列。`up` を回転させるとループ・ひねりになる(R-13)。`width` は路面幅(レーン移動の可動域) |
| `spawn` | 開始 distance と 4 人分のレーンオフセット |
| `goal` | ゴール判定の distance(R-05) |
| `fall` | スプライン路面からの相対 height がこの値を下回ったら落下(R-05) |
| `coins` | コイン配置(スプライン座標)。個数の合計がランク計算の分母(R-11) |
| `rank` | 評価。`score = 0.6 × スコア率 + 0.4 × min(1, parTime / クリアタイム)` を上から判定。(変更 2026-09-12 P21)コイン取得率 → スコア率(コンボ倍率込み)へ差し替え |
| `terrain` | (P11 追加・省略可) 地形の見た目。省略時は従来どおり heightScale=0 の平坦 grass 地形 |
| `boosts` | (P21 追加・省略可) ブーストパッドの配置。踏むと一定時間だけ最高速が上がる |

### boosts セクション(P21 追加)

```json
"boosts": [
	{ "distance": 350.0, "lateral": 0.0, "width": 6.0 }
]
```

| フィールド | 意味 |
|---|---|
| `distance` | スプライン距離。**この位置を跨いだフレーム**で発動する(単純比較だと最高速で取りこぼす) |
| `lateral` | パッド中心の横位置 |
| `width` | パッドの幅。`|プレイヤーの lateral − lateral| <= width/2` で踏んだ判定 |

- 省略可。無ければブーストパッドの無いステージになる。
- ランク計算には影響しない(タイムを通じて間接的に効く)。

### terrain セクション(P11 追加)

```json
"terrain": {
	"heightmap":    "Assets/Terrain/Stage01_heightmap.png",
	"splatmap":     "Assets/Terrain/Stage01_splatmap.png",
	"heightScale":  34.0,
	"heightOffset": -3.0,
	"resolution":   256
}
```

- `heightmap` は R チャンネル 8bit(高さ = heightOffset + R/255 × heightScale)。
  `heightOffset` は地形エンティティの Y になる(省略時 0)。
- **コース回廊は「最寄り路面 y − 0.7m」に追従**させてベイクする。Catmull-Rom の
  アンダーシュートでスプラインが y<0 に沈む区間でも地形が一緒に下がり、路面が
  地面へ埋まらない(負の高さは heightOffset で表現)。丘でも同様に追従する。
- ただし追従の種にするのは**接地している路面サンプルだけ**(P19)。`up.y >= 0.90` かつ
  進行方向の勾配 `|dy/ds| <= 0.40` を満たす区間のみ。ループのように路面が空中へ
  立ち上がる区間まで追従させると足元だけ地形が隆起し、同じ XZ を通る往復の平坦な
  路面が埋まる。ループ区間は種を置かず、入口/出口の高さが距離場で伝播して**真下は平ら**になる。
- `splatmap` は R=grass / G=snow / B=rock の混合比(エンジン側で正規化)。
- 画像は `Game/Tools/bake_stage_terrain.py` で .stage.json から生成する(座標対応・
  回廊幅などの定義はスクリプト側が一次資料)。地形の原点/terrainSize の計算は
  `CreateStageWorld`(コース AABB + マージン 60m の正方形)と同一式で焼くこと。
- すべて省略可。`heightmap` 省略時は平坦、`splatmap` 省略時は grass 単色。

- ゲームオーバー時(落下でリタイア)はランクなし。
- 補間は Catmull-Rom(制御点を通る・実装が単純)。`up` も球面補間して連続にする。
- コインが多い場合の量産は、当面 JSON を AI に生成させる運用とし、
  必要になったらエディタ拡張を検討(スコープ外)。

## 4. ロード経路

1. `LoadingState` が `.stage.json` を ThreadPool で読みパース → `StageData`(不変)を構築。
2. `level` を `LevelManager` で非同期ロード(既存経路)。
3. 両方の完了で、`StageData` からコイン・ゴールの Entity 群を遅延生成
   (既存 Prefab/Spawner の遅延ビルド経路を流用)して InGame へ。
