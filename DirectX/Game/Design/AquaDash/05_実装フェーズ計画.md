# 05. 実装フェーズ計画

> 対象コミット: ccfce22 / 最終更新: 2026-09-06

各フェーズは「設計確認 → 実装 → 評価」のサイクル(スキル `feature-dev-cycle`)で進める。
**1 フェーズ = 1 回のビルド・実機確認・コミット**を原則とし、評価チェックが埋まるまで
次フェーズへ進まない。評価結果は本書のチェックボックスに反映する。

## フェーズ一覧

| フェーズ | 内容 | 主な対応要求 | エンジン変更 |
|---|---|---|---|
| P0 | フォルダ/プロジェクト登録、GameFlow への状態骨組み追加(Title 仮 → InGame 空 → Result 仮の一巡) | R-01 | なし |
| P1 | スプライン走行の最小実装: Stage01(直線 + カーブ)、1 人走行、ジャンプ、自動カメラ | R-03, R-08, R-09 | なし |
| P2 | コイン + HUD(時間 / コイン / 速度)+ 判定 | R-11, R-14 | なし |
| P3 | ゴール / 落下 → リザルト(背景維持 + ランク + 3 択) | R-04〜R-06 | なし |
| P4 | ループ(up 回転)+ 重力方向変化の走破 | R-13 | なし |
| P5 | 4 人 / 4 パッド / 分割画面 | R-07 | **ビュー配列描画** |
| P6 | モーションブラー + FOV 等スピード感仕上げ | R-10 | **ポストパス追加** |
| P7 | ミニマップ + タイトル画面刷新(ステージ選択 UI + 仮アート)+ ステージを 3 分規模へ拡張 | R-01, R-02, R-12 | なし |

- P5/P6 のエンジン内部設計は着手時に `DirectX/設計書/01_レンダリング設計.md` へ追記してから実装する。
- 新規ファイル追加時はスキル `vs-project-files` に従い vcxproj / filters へ登録する。

## 評価チェックリスト

### P0
- [ ] ビルドが通り、仮 UI で Title → InGame → Result → Title が一巡する

### P1
- [ ] スティックで加減速・レーン移動、A でジャンプできる
- [ ] カメラが自動追従し、カーブで破綻しない
- [ ] レベルロードが非同期(ロード中に LoadingScreen が動く)

### P2
- [ ] コインを取ると枚数が増え、SE/エフェクトが出る
- [ ] HUD 3 種(時間 / コイン / 速度)が正しい値を表示する

### P3
- [ ] ゴールでクリア、落下でゲームオーバーになる
- [ ] リザルト背景がインゲームの 3D 世界のまま
- [ ] 「タイトルへ / もう一度 / 次へ」がすべて機能する(もう一度はロードなし)

### P4
- [ ] ループを最高速で走り切れ、途中で減速すると落ちる
- [ ] ループ中のカメラロールが自然

### P5
- [ ] 4 パッドで 4 分割同時プレイできる
- [ ] 分割時もフレームレートが実用範囲(要計測、目標 60fps)

### P6
- [ ] 最高速でモーションブラー + FOV 拡大が効く
- [ ] タイトル / リザルトに副作用がない

### P7
- [ ] ミニマップが機能する
- [ ] タイトルがステージ選択付きの新デザインになっている
- [ ] 1 プレイが約 3 分の規模になっている
- [ ] [00_企画概要.md](00_企画概要.md) の受け入れ条件をすべて満たす
